## 1. Identification du jeu

- Nom : **Huss Valley** (ce que l'utilisateur a écrit "Eusvalet"). Le jeu existe bien. **[V]**
- Page Roblox (vue dans les résultats de recherche, mais pas consultable ici) : https://www.roblox.com/games/112568283214131/Huss-Valley **[V]**
  - D'autres IDs apparaissent sur des trackers : rowatcher `10764627709`, rolimons `107535308163741`. Ce sont peut-être des copies ou des places liées. **[S]**
- Développeur : "Ve3" selon plusieurs guides, "Huss Valley Official" selon un tracker. Sortie vers août 2026, "Update 4" vers sept.-oct. 2026. Environ 1K joueurs simultanés et environ 420K visites (rowatcher). **[S]**
- À ne pas confondre avec **"Escape Huss Valley"** (autre jeu, groupe "hahaa", jeu d'évasion dans une ville). **[V]**
- Univers : "Folk Valley". Huss Valley y est une vallée froide et sombre, au milieu de la forêt Folk (lore fandom). **[S]**

## 2. Gameplay (ce qui est le mieux documenté)

- **Équipes** : jusqu'à 16 joueurs par match (le tracker indique 30 places par serveur). Au départ, **1 Chaser** est tiré au hasard et tous les autres sont des **Runners**. **[V]**
- **But des Runners** : traverser l'arène d'un bout à l'autre, **3 fois de suite**, sans "team wipe" (élimination de toute l'équipe). **[V]**
- **Tag** : un coup de couteau du Chaser met le Runner **à terre (downed)**. Un coéquipier peut le **réanimer** (touche E, dans une "danger zone" que le Chaser surveille). Selon d'autres sources, le Runner touché **devient Chaser** pour la suite, comme dans un tag "infection". **[S]**
- **Types de manche** (une seule famille de wikis) : poursuite en arène ouverte. Quand le groupe s'amenuise, "Choose the Chicken" : le lobby désigne un Runner cible que le Chaser doit éliminer avant la fin du timer. Avec très peu de joueurs : duel 1v1 en arène. **[S]**
- **Fin de manche** : tous les Runners sont attrapés, ou le timer expire. Une phase de spawn d'environ 5 à 10 s précède la manche (estimation non sourcée). **[S]**
- **Économie** : des **Gems** pour les capacités permanentes, des **Coins** pour les consommables à usage unique. Les deux se gagnent en fin de match selon la performance. Des Gems sont aussi ramassables au sol pendant la course. **[V]**
  - Exemples de capacités Runner : Cloak (invisible 3 s, 1000 Gems) et Pocket Door (bloque le Chaser 6 s, 400 Gems). Côté Chaser : Rufus's Leash (attire un Runner de 6 studs). **[S]**
  - Une capacité doit être **équipée dans le loadout avant de rejoindre la file**. Une seule capacité est active par match. **[S]**
  - Des récompenses gratuites et une "free ability spin" sont disponibles sur minuteur. **[S]**
- **Événement** "Football Vs Futbol" (oct. 2026) : on choisit l'Équipe Rouge (football américain) ou l'Équipe Bleue (soccer), avec des paliers de points d'équipe à débloquer. **[S]**

## 3. Sensation de mouvement (point clé pour Hunt or Hide)

- **Mouvement à inertie** : l'accélération est progressive. Quand on relâche la touche, le personnage **glisse puis décélère**, il ne s'arrête pas net. **[V]** (plusieurs guides concordent)
- **Dash latéral** : tenir W, maintenir A ou D, puis appuyer sur Espace. On obtient une impulsion **diagonale avant-gauche ou avant-droite**. Il n'y a pas de dash vers l'avant ni de touche de sprint. **[S]** (schéma "fan wikis")
- **Stop instantané** : la touche **Alt** annule tout l'élan et permet de repartir en sens inverse sans glisser. C'est la base des feintes ("jukes"). **[S]**
- **Contrôles officiels**, d'après la description du jeu citée par des tiers : Vault = Espace, Slide = C, Shift Lock = Ctrl gauche, Ability = Q, Journal = J, Get Task = T, Leaderboard = Y. **[V]** pour la description. Elle contredit en partie le schéma "Espace = dash / Alt = stop" : les deux ont peut-être existé selon les versions.
- [I] Pour Hunt or Hide : vitesse qui monte en 0,3 à 0,5 s, friction qui ramène à zéro en environ 0,4 s, un dash latéral avec cooldown, une touche stop qui coupe la vélocité. C'est cohérent avec ce qu'on lit sur Huss Valley.

## 4. Maps

- Arène principale : une **arène "industrielle" de Folk Valley**, très encombrée, sur plusieurs niveaux : maisons, toits, ruelles, caisses ("Crate Yard"), escaliers ("Stairwell Pocket"), rampes. Le terrain se lit en 4 types de zones : **goulets (choke points)**, **maisons** (elles cassent la ligne de vue), **sol ouvert** (rapide mais exposé) et **danger zone** (réanimation). **[S]**
- Les Runners apparaissent d'un côté et doivent rejoindre l'autre bout : la lecture est **linéaire, de bout en bout**. **[V]**
- Autres noms de maps cités une seule fois : "The Valley" et "The Dunes". **[S]**
- L'Update 4 a déplacé ou ajouté des danger zones et des toits. **[S]**

## 6. (OBSOLÈTE, remplacé par la section A) Proposition de layout inférée

L'idée : reprendre l'esprit "vallée froide, crépuscule, village industriel" et l'organisation fonctionnelle d'un lobby de jeu de tag Roblox, avec un design 100 % original.

```
                     N  (fond : falaises / forêt de sapins sombres, brume)
   +-----------------------------------------------------------------+
   |  [LEADERBOARDS]  panneaux muraux (Victoires / Tags / Niveau)    |
   |                                                                 |
   |  +---------+        +---------------------------+   +---------+ |
   |  | BOUTIQUE|        |   PORTAIL / QUEUE PADS    |   | VOTE MAP| |
   |  | capacités        |  [Hunter]  [ Hide ]  [Q]  |   | 3 pads  | |
   |  | (Gems)  |        |  zone surélevée + timer   |   | + écran | |
   |  +---------+        +-------------+-------------+   +---------+ |
   |                                   |                             |
   |  +---------+     place centrale (pavés, lampadaires,  +-------+ |
   |  | CONSO   |     braseros, caisses) = zone d'essai    | ROUE  | |
   |  | (Coins) |     du mouvement : dash / stop / slide   | daily | |
   |  +---------+              ( SPAWN )                   +-------+ |
   |                         cercle de spawn                         |
   |  [ mini-parcours d'entraînement : caisses, rampe, muret ]       |
   +-----------------------------------------------------------------+
                     S  (entrée / vue caméra d'arrivée)
```

- Taille indicative : une place d'environ 120 x 90 studs. Le spawn est au sud et regarde vers le nord, vers le portail de queue (point focal). Boutiques sur les côtés ouest et est, leaderboards au fond.
- Ambiance proposée : crépuscule froid (ClockTime environ 18,5), brouillard léger bleu-gris, Atmosphere avec une densité d'environ 0,35. Matériaux Cobblestone, WoodPlanks, CorrodedMetal et Slate. Points chauds orange (lampadaires, braseros) qui contrastent avec le bleu nuit. Accent rouge pour le côté Hunter, accent cyan pour le côté Hide.
- UI de lobby proposée : monnaies (Gems et Coins) en haut à gauche, bannière d'événement en haut à droite (comme Huss Valley), boutons Boutique, Loadout, Journal et Classement en colonne à gauche, bouton "PLAY / Queue" en bas au centre.
- UI en match proposée : timer et compteur de traversées (x/3) en haut au centre, rôle (Hunter/Hide) en haut à gauche, capacité (Q) et cooldown du dash en bas à droite, liste des joueurs (vivants, à terre) à droite.
